# Airbnb New York Price Analysis Project
## Research Question
What factors influence the listing price of Airbnb properties in New York City?

## Dataset Source and Usage Permissions
Dataset is the New York City Airbnb 2019 open dataset from Kaggle. It is available for educational and non-commercial use. The dataset has been anonymized and contains no private personal data.

## Methods and Tools Used
Python, Pandas, Matplotlib and Seaborn.
Exploratory data analysis, data cleaning to remove price outliers, descriptive statistics and visual analysis.

## Key Findings and One Limitation
Key Findings: Listings in Manhattan have the highest average price among all regions. Entire home/apt type rooms are significantly more expensive than private rooms and shared rooms.
Limitation: The dataset does not include the exact location coordinates and tourist season information, so we cannot analyze seasonal price fluctuation.

## Instructions for running the analysis
1. Clone this repository to your local machine.
2. Install dependencies: pip install -r requirements.txt
3. Open airbnb_analysis.ipynb in Jupyter Notebook.
4. Run all cells step by step to reproduce the analysis and visualizations.
